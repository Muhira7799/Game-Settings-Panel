# 🎮 Game Settings Panel

A simple and responsive **Game Settings Panel** built with **HTML and CSS**.
The project demonstrates how to create custom-styled checkboxes and organize game settings in a clean card-based interface.

## 📌 Features

* 🔊 Sound Effects setting
* 🎵 Background Music setting
* 🎯 Hard Mode setting
* 📳 Haptic Feedback setting
* ✅ Custom-designed checkbox buttons
* 🎨 Clean and simple user interface
* 📱 Responsive viewport setup

## 🛠️ Technologies Used

* **HTML5** – For the structure of the settings panel
* **CSS3** – For styling, layout, custom checkboxes, transitions, and shadows

## 📂 Project Structure

```text
Game-Settings-Panel/
│
├── index.html

└── README.md
```

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/Game-Settings-Panel.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional dependencies or installation are required.

## 🎨 Custom Checkbox Design

The default browser checkbox appearance is replaced using CSS:

* Custom yellow border
* Rounded corners
* Hover-friendly cursor
* Smooth transition
* Yellow background when selected
* White checkmark when checked

## 📸 Preview

The interface contains a centered **Game Settings** card with four customizable settings:
